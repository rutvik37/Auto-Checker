Privacy Policy

Last updated: August 2026

1. Introduction

QA Spelling Auto-Checker ("we", "our", or "us") respects your privacy. This Privacy Policy outlines how we handle website scan data, technical logs, and user configurations when using our automated quality assurance application.

2. Information We Collect

Our application collects target URLs submitted for scanning, extracted visible web page content, candidate spelling candidates, and scan configuration settings necessary to execute automated spelling analysis.

3. Website Scanning Data

Extracted visible web text is analyzed locally using dictionary rules and optional AI batch validation. Raw website text extracted during scanning is used exclusively for spelling error identification and stored in local SQLite database caches.

4. Data Retention & Security

Scan histories, issues logs, and custom dictionary entries are stored within the application database. Administrative user sessions and API tokens are secured behind role-based authentication controls.

5. Contact Information

For questions regarding this policy or data processing, please contact us at support@example.com.
