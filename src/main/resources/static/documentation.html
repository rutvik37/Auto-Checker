Documentation & System Guide

Comprehensive guide to configuring, running scans, and managing custom dictionaries.

1. Quick Start Guide

To start auditing a website, open the main website interface on http://localhost:9090. Enter the target website URL into the Website Spell Check card, configure your scan parameters, and click Start Scan.

2. Crawl Parameters

  • Max Pages: Controls the maximum number of unique URLs the crawler will discover and inspect (e.g., 50 to 500 pages).
  • Crawl Depth: Defines how many link levels deep from the seed URL the crawler will navigate (e.g., Depth 1 = target page only, Depth 3 = up to 3 link hops).

3. Detection Pipeline

The scanner processes pages through an 8-stage hybrid detection pipeline:

  1. Jsoup Text Extraction: Parses HTML body and extracts visible text content while ignoring scripts and CSS.
  2. LanguageTool Engine: Flags preliminary spelling candidates using American English dictionaries.
  3. Pre-filtering & Space Normalization: Filters URLs, emails, numbers, and space variations.
  4. Custom Dictionary Check: Verifies words against global and user custom dictionaries (`global.txt` and `user.txt`).
  5. SQLite Local Cache: Checks local SQLite database (`validation_cache`) for pre-verified decision records.
  6. Groq AI Batch Validation: Validates unresolved candidates using Groq LLM endpoint (`groq/compound`).
  7. Database Issue Saving: Persists verified `TYPO` issues into SQLite database.
  8. Live UI Streaming: Streams progress and detected issues to the web UI in real-time via Server-Sent Events (SSE).

4. Exporting Reports

Completed scan results can be exported directly from the public website or Admin Panel in multiple formats: CSV, Excel (.xlsx), or JSON.
