Help Center & FAQ

Find answers to common questions about automated website scanning and spelling detection.

What is QA Spelling Auto-Checker?

QA Spelling Auto-Checker is an automated quality assurance system that crawls web applications, extracts visible text content, and detects spelling mistakes using dictionary and AI validation engines.

How does website scanning work?

The crawler visits the seed URL, extracts all visible text, parses internal links up to your configured crawl depth, and sends extracted words through the hybrid spelling validation pipeline.

What does Max Pages mean?

Max Pages sets the maximum number of unique web pages the scanner will crawl during a single scan session.

What is Crawl Depth?

Crawl Depth specifies how many link levels away from the starting URL the crawler will follow. A depth of 1 scans only the landing page, while depth 3 scans up to 3 links deep.

How are duplicate spelling issues handled?

Multiple occurrences of the same misspelled word on a single page are automatically deduplicated and grouped under a single issue record.

Can technical words be ignored?

Yes! Technical terms (e.g. JavaScript, PostgreSQL, Playwright) and custom words added to global or user custom dictionaries are automatically whitelisted and ignored.

Can scan results be exported?

Yes, all scan results and detected issues can be exported in CSV, Excel, or JSON format from the application interface or Admin Panel.
